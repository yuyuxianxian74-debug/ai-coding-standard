# 项目专属规范模板

根据实际需求填写，不适用项注明原因或省略。未知事实标为待确认，不虚构指标。
- 项目定位：目标、用户、场景、核心价值、MVP、范围外事项。
- 调研：现有实现、可复用方案与素材、许可证、兼容性、采用或拒绝理由。
- 技术选型：语言、框架、版本、替代方案与成本。
- 架构：模块职责、依赖、数据流、接口契约、目录及状态管理。
- 业务规则：关键约束、数据模型、异常与边界。
- 编码：项目特有风格、命名、异常、日志、依赖约定。
- 视觉：参考图、设计系统、交互及动画状态、资源预算（适用时）。
- 质量：测试分层、独立验收依据、回归、真实运行命令和证据；Agent 项目补充 Eval、工具权限、预算；UI 项目补充截图与交互。
- 性能：实际指标及测量方法，不凭空制定目标。
- 安全：权限、秘密、隐私、数据隔离及高风险操作。
- 发布：环境、构建、部署、备份、回滚、监控及验收。
- 人工介入：低风险自主执行；核心功能/复杂 Bug 先审阅；架构、数据、安全、生产及不可逆变更必须明确授权。
- 项目特有风险、完成定义、规范维护机制。

输出供人工审阅；重要事项确认后再实施。规范变化记录原因及影响，不自动降低验收要求。
