# 单任务工作模板

## 开发前
任务编号、目标、规格来源、依赖、修改范围、禁止范围、复用调研、方案及理由、风险、验收条件、实际测试命令。检查 Git 与未提交修改。必要时等待人工确认。

## 开发中
只执行授权范围；保持可运行、可验证；发现新需求或重大架构变化先反馈；使用已有组件，避免过度设计。

## 交付
- 本次任务与状态
- 调研及复用结果
- 实现方案、修改文件与影响范围
- 核心执行原理、数据流、排障入口（重要模块）
- 实际测试、构建、截图或运行证据；未执行项目单列
- Git diff 审查、风险、遗留及回滚方式
- 更新任务、进度和相关文档；下一步及依赖

## 完成检查
规格符合；功能完整；相关测试与构建通过；无阻塞缺陷；无越权变更；必要审查及文档完成；适用人工验收通过。否则标未完成或未验证。未经授权不推送或部署。
